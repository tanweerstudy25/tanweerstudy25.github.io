Professional Portfolio Website Project

This website serves as my professional online portfolio for presenting IT experience, technical skills, certifications, projects, technical notes and professional information. The website is built with HTML5, CSS3 and JavaScript, maintained through GitHub, published with GitHub Pages, connected to tanweer.site, registered through Namecheap, managed through the Cloudflare DNS layer and monitored using Google Analytics 4 and GoatCounter.
