PROJECT OVERVIEW

Introduction

A complete overview of how this portfolio website was planned, developed, published and monitored.

Professional Portfolio Website Project

The Tanweer Ansari Personal Portfolio Website was created as a professional online platform to present my IT experience, technical skills, certifications, projects, technical notes and professional profile.

The website was developed primarily using HTML5, CSS3 and JavaScript instead of relying completely on a ready-made website builder. This provides greater control over the website structure, appearance, animations, responsive design and future development.

GitHub is used for source-code management and version history, while GitHub Pages provides website hosting and publishing. The website is connected to the custom domain tanweer.site.

Google Analytics 4 and GoatCounter were integrated to monitor website visitors, page views, traffic sources, visitor locations, devices and general website usage.
